## v1.4.0：永远双人、AI 代班、随机大招

### 1. 取消单人/双人分野，永远双人

没有「单人模式」「双人模式」了 —— 两个席位恒在。一个人玩时，落单的座位由 **AI 副驾驶** 接管：
连续 **5 秒**没有收到该席位的任何按键，自动切换为 AI 控制；玩家**任意一键按下立即夺回**。
AI 用**势场算法**（威胁排斥 + 擦弹诱导 + 道具吸引 + 目标对齐），会主动走位闪避、贴着弹幕蹭擦弹充能、
并在弹幕糊脸 / 残命时自动放招，强度足以独自推进关卡。

### 2. 随机大招系统（大招键 = 每次都不一样）

原来大招 = 固定清屏。现在大招键释放的是 **8 种随机大招之一**，释放后立刻抽下一发，
HUD 实时预告「下一发是什么」—— 把随机性变成期待感而非失控感：

| 大招 | 效果 | 大招 | 效果 |
|---|---|---|---|
| 新星爆破 | 清屏 + 三段冲击波 | 弹幕骤雨 | 天降坠星砸穿敌阵 |
| 僚机风暴 | 4 架僚机环绕自动索敌 | 要塞护盾 | 护盾 + 免伤一次 + 散射 |
| 引力井 | 吸走敌弹后塌缩爆发 | 混沌轮盘 | 纯随机意外（金雨/白送词条/弹幕转经验…） |
| 轨道炮 | 跟随自机的贯穿光束 | 时空凝滞 | 敌人与敌弹减速至 1/3 |

遵循配色契约：我方效果一律冷色（蓝 / 青 / 白 / 淡金），暖色仍专属有害物。

## 为什么现在每局都不一样（v1.3.0）

v1.2.0 之前的版本有骨架没血肉：一整关火力只从 1 级升到 4 级、武器全靠随机道具被动切换、
平均 **10 秒才击破 1 个敌人**、连击永远连不起来（窗口 1.67 秒 < 击破间隔）——
玩家全程只做「移动 + 按住射击」两件事，**没有做过任何一次选择**，所以每局都一模一样。

v1.3.0 针对这四点重做：

### 1. 局内 Build：升级自动强化（核心）

击破敌人掉**经验球**（自动磁吸），攒够经验升级时**自动发放随机词条** ——
**零弹窗、零选择、零抢键**，全程照常走位射击，强化提示只在机体旁飘一行小字：

- 不打断操作：升级时世界**不减速**、不弹菜单、不占用方向键 / 射击键
- 词条真正改变**弹幕形态**，不只是改数字：

| 词条 | 效果 | 词条 | 效果 |
|---|---|---|---|
| 高速装填 | 射速 +18%/级 | 爆裂弹头 | 命中后炸出碎片 |
| 弹头强化 | 伤害 +25%/级 | 击破溅射 | 击破时向四周喷弹片 |
| 双联发射 | 每次多打 1 发 | 环绕炮台 | 召唤自动炮台（最多 4 座） |
| 穿甲弹芯 | 子弹多穿 1 个 | 僚机增编 | 僚机 +1 对（最多 3 对） |
| 临界打击 | 12% 概率 3 倍伤害 | 牵引力场 | 拾取范围 +70% |
| 自动索敌 | 子弹自带追踪 | 近接增幅 | 擦弹充能 +60% |
| 力场护盾 | 每 18 秒免伤 1 次 | 超载延长 | 超载 +1.2 秒 |

词条按**常见 / 稀有 / 史诗**三档加权抽取（10 : 5 : 2.5），每级只抽未封顶的条目。

### 2. 擦弹 → 超载 OVERDRIVE

原来擦弹只加 50 分 —— 而分数在弹幕游戏里根本不是驱动力。现在擦弹**为超载充能**：

- 充能满格**自动触发** 3 秒超载：火力翻倍（伤害 ×2、射速 ×1.35、弹数 +1）
- 超载期间**擦弹范围扩大 1.6 倍**，形成「越贴越强、越强越敢贴」的正循环
- 视觉上是暖金色呼吸环 + HUD 上的 OVERDRIVE 条，一眼知道自己现在很猛

从「躲弹幕」变成「钻弹幕」。

### 3. 关卡节奏重做

| | v1.2.0 实测 | v1.3.0 实测 |
|---|---|---|
| 首个 Boss | 135 秒 | **48 秒** |
| 一整关 | 160 秒 | **54-65 秒** |
| 击破 | 16 个 | **76-390 个** |
| 最高连击 | 8（倍率失效） | **66**（倍率封顶 x4） |
| 火力等级 | 只到 4/5 | **5/5 全展开** |
| 全程道具 | 11 个 | **36 个** |

配套修了一个真实的设计缺陷：Boss 原本要求**场上敌人全部清零**才登场，而 `turret` / `hover`
类敌人永远不会自己离场 —— 漏掉一个角落炮台，关卡就无限拖住（实测被拖到 135 秒）。
现在清场即触发，超时 4 秒强制登场并让残敌撤离。

另外每关切成**三个节奏高点**：段末登场**精英机**（血厚、环形弹幕、必掉火力武器与大量经验），
把「一路平推」变成有起伏的推进。

### 4. 长线牵引：每日挑战 + 成就

- **每日挑战**：用日期做种子的固定词条池（6 选）+ 固定强度档位（1.00-1.35），
  所有玩家当天面对同一套随机；当天最佳分单独记录
- **成就** 8 项：首捷 / 连击大师 / 刀尖起舞 / 军火库 / 零失误 / 超载狂人 / 无尽勇者 / 五十万俱乐部
  结算时即时提示新解锁项，菜单上常驻进度

## 一眼分辨敌我（v1.2.0 视觉契约）

弹幕游戏里最贵的资源是玩家的注意力。所以有害物与有利物在**颜色、形状、描边**三个维度上完全相反，余光扫一下就能分类：

| | 颜色 | 形状 | 描边 | 动效 |
|---|---|---|---|---|
| **有害**（敌弹 / 敌机 / Boss） | 暖色区：红 `#ff4864`、橙 `#ffa42e`、洋红 `#ff2fae`、紫 `#c15cff` | **尖角星芒**（4/5/6 角，角数对应不同攻击套路） | 深红**暗描边** | 出膛 7 帧内套一圈收缩白环做入屏预警 |
| **有利**（道具） | 冷色/亮色：青、蓝、薄荷、白金 | **圆形徽章** + 中心符号（P / W / B / S / ♥ / ★） | 纯白**粗环** + 内圈彩色细环 | 外圈白光**呼吸脉冲** |

三条硬规则：

1. **敌人不再是绿色**。「绿色 = 安全」是直觉，所以螺旋弹与轰炸机原本的绿色全部改成橙红，敌方一律暖色。
2. **我方一律冷色**：机身青/琥珀（1P/2P 区分）、我方子弹是冷色细长光矢，追踪导弹由紫改薄荷绿。
3. **5 台 Boss 涂装全部暖色**（红/橙/紫/洋红/金），原先的蓝、绿涂装会让人觉得"这是自己人"。

主菜单里也放了同款图例，不用记规则，开局前扫一眼即可。

## 画面自适应

纵向高度恒定 800，**横向宽度随窗口比例自适应**（420 - 720），把宽屏两侧的黑边换成可用战场：

| 视口 | 逻辑分辨率 | 实际显示 |
|---|---|---|
| 1280 × 900（桌面宽屏） | 720 × 800 | 810 × 900 |
| 1100 × 1000（近方形） | 720 × 800 | 900 × 1000 |
| 390 × 844（手机竖屏） | 420 × 800 | 390 × 743 |

关卡脚本里的横向坐标按参考宽度 480 等比映射（`enemies.js` 的 `X()`），所以编队在任何宽度下都保持对称；战场变宽时自机移动速度同步补偿（最高 ×1.25），避免横向机动变迟钝。

## 玩法

**每人只要三个键**：方向 + 射击 + 大招，外加全屏共用的暂停键。按住的射击键同时承担「连点 / 蓄力」两种节奏。

| 玩家 | 移动 | 射击（按住 0.8 秒自动蓄力炮） | 大招（清屏 + 无敌） |
|---|---|---|---|
| **1P** | `W A S D`（单人时方向键同样可用） | `空格` | `M` |
| **2P** | `↑ ↓ ← →` | `小键盘 回车` | `小键盘 +` |
| 暂停 | `P` / `Esc` | — | — |

手机 / 平板：拖动屏幕移动（相对位移，手指不遮挡机体），自动射击，右下角 `B` 按钮放 1P 大招。

## 弹幕设计（v1.4.5）

- **减量提质**：同屏敌弹硬上限 120（我方 80）；出弹间隔全线拉长约一倍，弹环 12 发 → 6 发、弹幕雨/螺旋大幅降频
- **我方少而重**：射速约减半、单发伤害翻倍（DPS 持平）——每发都有分量，实测 60 秒：敌弹均值 8.8/峰值 32，我方弹均值 27/峰值 63，两侧同量级
- **速度统一量级**：敌弹 1.4~2.2 / 我方弹 5~7（px/帧）—— 每一发都看得清、跟得上，密集恐惧症友好
- **弹种辨识**：红·瞄准直射 / 橙·双向散弹 / 品红·蛇行弹（左右摆动）/ 紫·慢速环弹 / 橙红·重型炸弹 / 追踪导弹 / 激光狙击（预警线）

- 一方坠机后不再互推（救援靠近信标不受干扰）；AI 代班同样遵守间距

- 残机耗尽**不再直接出局**：坠机位置留下**救援信标**（队友色双环脉冲），缓缓下落
- 存活队友**飞过去接触**即救援成功：队友带 2 残机 + 3 秒无敌归队，全屏清弹安全入场，救援者 +5000 分
- 信标漏出屏底会在 3 秒后从顶部重新入场 —— 救援永远有机会，但要去弹幕里冒险拿
- **AI 代班也会主动营救**（信标是强吸引目标，威胁规避仍然生效）
- 双方都坠机才算游戏结束；单人坠机无人可救照常结算

## 两人同屏（本机一台电脑）

点「开始游戏」即两人同屏一起玩；想玩无尽或每日挑战再选对应入口。坐在同一台电脑前一人一边：

- **共用**：分数、关卡进度、Boss、动态难度 Rank —— 一起扛同一波弹幕
- **各自独立**：残机、大招数、火力等级、武器类型、速度、连击倍率、擦弹数
- **公平掉落**：火力道具成对掉、武器道具三种各掉一个，避免两人抢资源
- **阵亡**：一人残机耗尽即「出局」（HUD 显示 `OUT`），另一位可以继续单挑；两人都出局才结算
- **辨识**：1P 青色机身 + 青环，2P 琥珀涂装 + 金环，机体下方标 1P / 2P
- 敌人（含 Boss 弹幕）自动瞄准**离它最近的玩家**，不会两人同时被同一发弹幕忽视

## 系统

**三武器**
- 火神炮 VULCAN：扇形散射，覆盖面广，适合清杂兵
- 激光炮 LASER：直线穿透（可穿 2 个目标），单体伤害最高
- 追踪导弹 MISSILE：自动索敌，走位吃力时的保底输出

拾取 `W` 道具切换武器；同色 `P` 道具升级火力等级（1→5）。

**火力等级**
1 单发 → 2 双发 → 3 三向 + 2 架僚机 → 4 强化 → 5 五向 + 僚机侧翼交叉火力。

**蓄力炮**：按住射击键 0.8 秒自动释放（不打断连射），三种武器对应三种阵型炮，需重新蓄力。

**炸弹**：初始 3 枚，上限 5 枚。清空全屏敌弹（每发折算分数）+ 约 1.5 秒无敌 + 对屏内敌人造成伤害。

**道具**：`P` 火力 / `W` 换武器 / `B` 炸弹 +1 / `S` 速度 +1 / `♥` 残机 / `★` 勋章（计分）。

## 关卡

5 关：边境星域 → 云海要塞 → 赤色峡谷 → 极地轨道 → 敌旗舰队。
每关约 2.5-3 分钟：杂兵波次 → 中段精英 → 关底 Boss。波次由时间轴数据表驱动（`enemies.js` 的 `TW.STAGES`）。

**Boss**：2 阶段血量分段（第 2 阶段在 66% 血、第 3 阶段在 33% 血触发），切换时全屏清弹 + 顿帧 + 屏震。
每台 Boss 左右各有一个**可拆解侧炮塔**，打掉后弹幕密度与形态随之改变，并掉落火力道具。

**无尽模式**：程序化波次持续加压，每 5 波出一台 Boss，血量随波次成长。

## 计分

- **连击倍率**：2 秒内连续击破累积，倍率 1.00 → 4.00（每杀 +0.05，上限 60 连），断链清零
- **擦弹 Graze**：敌弹在自机判定点 22px 内掠过 +50 分并溅出火花
- **勋章 / 过关奖励**：勋章 1500 分；过关额外结算 10000 + 炸弹数 ×1500 + 擦弹数 ×20
- **残机奖励**：每 80000 分（之后每 120000 分）残机 +1
- 最高分写入 `localStorage`（键 `tw_best`）

## 动态难度 Rank

隐藏值 0-100，随火力提升（+8）、击破（+0.18/杀）、擦弹（+0.05）与时间缓慢上升，死亡时 -28。
影响敌弹速度（最高 +25%）与敌人开火频率（最高 +40%）。目的：让高手始终有压力，也让新手不至于被自己的高火力反噬。

Boss 阶段切换与击破顿帧·敌弹暗描边 + 入屏预警白环·道具呼吸光环·3px 自机判定点·常态淡显擦弹圈·程序化音效（WebAudio 合成）。

## 技术

- 纯 Canvas 2D，纵向恒定 `800`、横向 `420 ~ 720` 随窗口比例自适应（`MIN_W` / `MAX_W`），按视口等比缩放，DPR 上限 2
- 宽度变化通过 `TW.setWidth()` 广播给 `enemies.js`；关卡脚本坐标经 `X(v) = v / 480 * W` 映射，编队始终按比例占满战场
- 固定步长 60Hz 逻辑 + rAF 渲染（累加器，最多补 5 帧）
- 精灵在初始化时**预渲染到离屏 canvas**，运行时只做 `drawImage`；战斗路径不使用 `shadowBlur`
- 实体上限：敌弹 420 / 我方子弹 260 / 粒子 700
- 玩家状态（残机 / 火力 / 武器 / 连击 / 擦弹）全部下沉到独立玩家对象，`G.players[]` 长度即 1P 或 2P；`G.player` 仅作为 1P 的读写快捷方式
- 我方子弹带 `owner` 标记，击破的连击与倍率结算归属开枪的那个人

```
index.html   入口与 UI 层（菜单 / 暂停 / 结算）
style.css    UI 样式
sprites.js   程序化矢量精灵（我方、敌机、Boss、弹丸、星云、白闪剪影）
fx.js        粒子特效、屏震、顿帧、WebAudio 合成音效
enemies.js   敌人行为、编队 helper、5 关波次脚本、Boss 攻击编排
game.js      引擎核心：输入、玩家、武器、碰撞、计分、关卡流程、渲染、HUD
```
