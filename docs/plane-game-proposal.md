# 《雷霆之翼 Thunder Wing》飞行射击游戏 · 开发方案 v0.1（待审）

> 目标：在 nexus-hub 仓库里新增一款**原创**竖版卷轴弹幕射击游戏，网页直开、桌面 + 手机双端可玩，
> 玩法致敬《雷电 / 打击者1945》，美术与命名全部原创（不叫"雷电"，规避版权）。

---

## 一、市面调研结论

| 代表作 | 年份 / 厂牌 | 核心机制 | 我们借鉴什么 |
|---|---|---|---|
| 雷电 Raiden | 1990 Seibu | 三武器切换（火神炮/激光/导弹）+ P 火力道具 + B 炸弹 + 僚机 + 多阶段 Boss | 武器切换与火力分级的主力框架 |
| 打击者 1945 | 1995 Psikyo | 六机体差异化、**蓄力射击**（僚机分离成阵型）、金块计分、"早回し" | 蓄力/副武器带来的节奏起伏 |
| 怒首领蜂 DoDonPachi | 1997 Cave | 超高密度弹幕、自机判定点极小（约 2px）、**擦弹 Graze** 计分、连击链 | 风险-回报：贴着子弹飞能拿分 |
| 东方 Project | 1996+ ZUN | 符卡制、弹幕编排艺术化、判定点可视化 | 弹幕"可读、可背、可练" |
| Sky Force Reloaded | 2016 | 3D 画面、金币养成升级、护盾、救援玩法 | 长线成长（可放到无尽模式） |
| 雷霆战机 | 2014 腾讯 | 战机/装甲/副武器/僚机四件套、无尽模式、好友排行 | 无尽模式 + 本地最高分榜单 |
| Geometry Wars | 2003 | 矢量霓虹、双摇杆 | 纯程序化美术的可行性（仓库已有同类） |

**结论**：市面最"耐玩"的作品不是靠画面，而是靠三件事 —— **火力成长的可感知曲线**、**风险与回报的张力**、**弹幕的可读性**。本方案把预算全部压在这三点上。

## 二、设计的六条公理

1. **打击感优先**：命中闪白、爆散粒子、顿帧、屏震，一次击破要"看得见重量"。
2. **火力成长看得见**：P 道具 1→5 级，每级形态变化明显（单发 → 双发 → 扇形 → 加僚机 → 满火力）。
3. **风险-回报张力**：满火力时敌人弹速/密度上升（Rank 机制）；贴弹擦身（Graze）加分。
4. **弹幕可读**：自机判定点仅 3px；敌弹高对比配色 + 入屏预警闪烁；敌弹速度低于玩家机。
5. **Boss 是多阶段的**：可拆解部件（打掉侧炮塔，弹幕形态随之改变），有破防期与狂暴期。
6. **节奏编排**：3 秒一次小反馈，30 秒一个小高潮，3 分钟一个 Boss。

## 三、游戏定位

- 类型：竖版卷轴弹幕射击（Vertical Scrolling Shoot'em up）
- 屏幕：逻辑分辨率 480×800，等比缩放居中，手机竖屏原生适配
- 技术：纯 Canvas 2D + 原生 JS，**零构建、零外部依赖、零图片素材**（全部程序化绘制 + WebAudio 合成音效）
- 入口：`thunder-wing/index.html`，接入 `games.html` 门户卡片，push 后 CF Pages 自动部署

## 四、核心玩法设计

### 1. 操作
- 桌面：WASD / 方向键移动，`J` 或 `空格` 射击，`K` 放炸弹，`Shift` 低速微调（显示判定点）
- 手机：手指拖动（相对位移，手指不挡飞机）+ 右侧射击/炸弹虚拟键
- 自动连续射击，按住即可

### 2. 武器系统（致敬雷电三系）
| 武器 | 颜色 | 特性 | 适合 |
|---|---|---|---|
| 火神炮 Vulcan | 红 | 扇形散射，覆盖广，单发伤害低 | 清杂兵 |
| 激光 Laser | 蓝 | 直线穿透，伤害高，宽度随火力提升 | 打 Boss / 列队 |
| 导弹 Missile | 紫 | 自动追踪，射速慢，伤害中 | 走位吃力时保底 |

- 拾取不同颜色道具即**切换**武器，同色则**升级**（1→5 级）
- **僚机（Wing）**：火力 ≥3 级出现 2 架僚机跟随射击；火力 5 级时僚机转为侧翼交叉火力
- **蓄力射击**：按住 ≥0.8s 松开，释放一次高伤"阵型炮"（僚机前推集火），有 2s 冷却 —— 借鉴 1945
- **炸弹 B**：清屏 + 1.5s 无敌 + 对屏内敌人造成伤害，初始 3 枚，上限 5 枚

### 3. 道具掉落
- `P`（火力）/ `W`（武器切换）/ `B`（炸弹 +1）/ `S`（速度 +1，上限 3）/ `♥`（残机，稀有）/ `★`（勋章，计分）

### 4. 关卡与波次
- 5 关，每关约 2.5–3 分钟：杂兵波次 → 中 Boss → 杂兵波次 → 关底 Boss
- 波次用**数据表驱动**（时间轴 + 编队模板），便于调难度与复用
- **早回し**：提前清完一波，下一波立即出场并给时间奖励分 —— 鼓励高手提速

### 5. Boss 设计
- 每个 Boss 2–3 阶段，血量分段；**可拆解部件**（打掉左右炮塔后主炮弹幕减半）
- 阶段切换时全屏清弹 + 短暂无敌 + 专用演出（破防顿帧 60ms）
- 弹幕原型库：环形齐射 / 扇形扇形 / 螺旋 / 追踪弹 / 激光扫射 / 交叉网

### 6. 计分
- 击破基础分 × **连击倍率**（2 秒内连续击破，倍率 1.0 → 4.0，断链清零）
- **擦弹 Graze**：判定点外 14px 内掠过敌弹 +50 分并点亮火花 —— 贴弹走位的回报
- 勋章/金块拾取、无伤通关奖励、残机奖励
- 最高分存 `localStorage`，Top 5 本地榜单

### 7. 动态难度（Rank）
- 隐藏值 0–100，随火力等级、连击数、存活时间上升，随死亡大幅下降
- 影响：敌弹速度 +0~25%、齐射密度 +0~40%、杂兵血量 +0~20%
- 目的：高手打得爽，新手不至于被满火力反噬

## 五、手感与表现细节（决定"好不好玩"的部分）

| 项 | 参数 |
|---|---|
| 命中反馈 | 敌机闪白 2 帧 + 12 粒爆散粒子 |
| 击破 | 小型爆炸 8 粒 + 冲击环；大型/Boss 24 粒 + 二次爆 |
| 屏震 | 普通击破 3px/0.1s；Boss 破防 8px/0.25s |
| 顿帧 Hitstop | Boss 阶段转换 60ms、Boss 击坠 120ms |
| 敌弹预警 | 入屏前 0.25s 半透明闪烁（尤其高速弹） |
| 自机判定 | 3px 亮点，低速移动时显形 |
| 背景 | 3 层视差滚动（星空 / 云海 / 地形），每关换色板 |
| 音效 | WebAudio 程序化合成：射击、命中、爆炸、拾取、警告 —— 无外部音频文件 |

## 六、技术方案

```
thunder-wing/
  index.html      入口（画布 + UI 层 + 版本徽标 v1.0.0）
  game.js         全部逻辑（约 2500–3500 行，单文件便于维护）
  style.css       UI 样式
  README.md       玩法说明
```

- **架构**：固定步长逻辑（60Hz 累加器）+ rAF 渲染；实体走**对象池**（子弹上限 400，敌机 80，粒子 600）
- **性能红线**：战斗路径禁用 `shadowBlur`；粒子用预渲染离屏 canvas；DPR 上限 1.75
- **全局句柄**：`window.__twGame` 暴露状态与 `frame(dt)`，供 Puppeteer 确定性测试
- **版本徽标**：主界面右下角显示 `v1.0.0`（沿用仓库铁律：改动即升版本）
- **状态机**：MENU → PLAYING → PAUSED → BOSS → RESULT

## 八、验收方式（沿用仓库 nexus-game-deploy 规范）

`thunder-wing/_test.js`（不提交）用系统 Chrome headless 跑：
- 页面无 `pageerror`；`window.__twGame` 存在且实体数组非空
- 输入断言：按方向键后自机坐标变化；按射击键后子弹数 +1
- 玩法断言：拾 P 道具火力 +1、炸弹清屏后敌弹数归零、Boss 血量分段切换阶段
- **像素断言**：`draw()` 后统计亮像素数量（防止渲染异常被 try/catch 吞掉）
- 压力：同时 200 发敌弹 + 60 粒子，连续 600 帧不掉到 50fps 以下
- 截图：主菜单 / 战斗中 / Boss 战 三张人工核对

## 九、需要你拍板的 4 件事

1. **美术风格**
   - A. 霓虹矢量（程序化绘制，最稳最快，推荐）
   - B. 复古像素（需要生成像素素材，周期更长）
   - C. 写实机甲（需找外部素材，版权/工期风险最高）
2. **关卡规模**：5 关（推荐）/ 8 关 / 先做无尽模式
3. **是否支持双人同屏**（WASD + 方向键两套，参考坦克大战）
4. **命名**：雷霆之翼 Thunder Wing（推荐）/ 苍穹猎手 Sky Hunter / 你有更好的名字？
