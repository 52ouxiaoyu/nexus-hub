基础操作
· WASD 移动 · 空格浇水：每次 +1 阳光，1 秒才能浇一次（按得再快也没用）——开局 0 阳光，找到房间开始浇水才有收入；站在蘑菇旁边浇水可以同时催熟小喷菇
· 点击空地 = 种植菜单；点击植物 = 弹出「升级 / 拆除」面板，面板上会写出升级收益（血量/产出），升级统一消耗 🦠孢子（蘑菇系产出），拆除直接移除植物

成长配方（唯一，不撞衫）
· 阳光菇 →(🦠5)→ 大阳光菇 →(🦠15)→ 向日葵 →(🦠40)→ 双子向日葵，逐级变大、产阳光更多
· 小喷菇(☀200 购买) 靠浇水喂大：浇水 40 → 胆小菇(产孢子×2) → 浇水 80 → 大喷菇(会喷射) → 浇水 160 → 忧郁菇(强范围喷射)
· 坚果 →(🦠10)→ 豌豆坚果(子弹跟踪·血量5000) →(🦠25)→ 射手坚果(跟踪·双发·血量6500) →(🦠40)→ 卷心菜坚果(投掷·血量8000) →(🦠60)→ 高坚果(血量10000) →(🦠100)→ 南瓜壳(血量15000)，逐级变大变硬
· 豌豆射手三选一分支：双发射手→(🦠60)→机枪射手 / 寒冰射手→(🦠40)→冰雪双发(减速) / 双向射手→(🦠50)→三线射手(扇形)
· 跟踪弹规则：豌豆坚果线的子弹在 260px 内自动追踪猛鬼，超出追踪区就变直线飞

🦠 孢子高级植物（蘑菇系随时间产出孢子）
· 地刺(🦠50)：贴地陷阱，猛鬼站上持续掉血，不会被啃
· 眩晕菇(🦠100)：每 6 秒冰冻猛鬼 2 秒
· 毁灭菇(🦠200)：超高攻击——猛鬼靠近即核爆（一次性）

👻 猛鬼规则：全场只有一只猛鬼，开局 20 秒出笼，每 45 秒升级：
普通僵尸 → 路障 → 铁桶 → 橄榄球 → 铁门 → 冰车（最终形态）
· 打倒猛鬼 8 秒后同级重生（升级不会停）；击倒最终形态冰车僵尸 = 胜利；HP 归零 = 失败
· 房间四周是河道，门口搭着木桥 + 坚果门板：你可以自由过桥，猛鬼得把门板啃穿（门板血量随坚果升级一起变硬）
