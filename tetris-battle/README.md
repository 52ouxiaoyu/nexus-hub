## 操作

| | 玩家 1 | 玩家 2 |
|---|---|---|
| 移动 | A / S / D | ← → / ↓ 软降 |
| 旋转 | 空格 | 小键盘回车 |
| 硬降 | 左Shift 或 Q | 小键盘0 / 右Shift |
| 道具 1/2/3 | F/G/H（备用 Z/X/C） | 小键盘 1/2/3（备用 , . /） |
| 必杀 | R（备用 E） | 小键盘+ / 右Ctrl |

## 道具规则

- 一次消 **2 行** 得 1 道具，**3 行** 得 2 个，**4 行（Tetris）** 得 3 个道具 + 1 充能
- 连击（Combo）每层 +1 必杀充能
- 道具栏 3 格塞满后再获得的道具转为必杀充能
- 攒满 **10 点充能** → 发动必杀「末日洪水」：6 行垃圾 + 迷雾 + 加速同时砸向对方
- 垃圾行攻击有 1.5 秒预警（中间栏红色箭头），护盾可完全抵挡一次攻击
- 任一方堆到顶即输
