# 🎮 葫芦兄弟：拯救爷爷（v2.0 重制版）

> 基于经典动画《葫芦兄弟》的**卡牌构筑闯关游戏**。选择一位葫芦娃，三章闯关、救出兄弟、集齐七子，唤醒金刚葫芦娃击败蛇精！

### 👉 [在线游玩](https://52ouxiaoyu.github.io/Calabash-Brothers/) · 双击 `index.html` 即可本地游玩（零依赖）

---

## ✨ v2.0 全新重制

旧版是纯文字随机事件游戏（大段文字 + 打字机 + 无穷点击，随机性大于策略）。v2.0 推倒重做：

| 维度 | 旧版 v1.x | 重制版 v2.0 |
|:--|:--|:--|
| 玩法 | 纯文字随机事件 | **回合制卡牌对战**（敌人意图可见、格挡 / 力量 / 易伤 / 虚弱） |
| 策略 | 基本靠随机数 | 卡组构筑 + 能量规划 + 意图应对 |
| IP | 葫芦娃 × 灭霸 × 诺基亚大乱炖 | 全程葫芦兄弟世界观（穿山甲、山泉、葫芦藤……） |
| 节奏 | 一次探索点 3~4 次才能继续 | 每屏一个决策，无文字轰炸 |
| UI | 三栏深色仪表盘 + 满屏 emoji | 米白宣纸底 + 水墨远山 + 七色点缀 |

## 🚀 核心玩法

- **选娃开局**：七位葫芦娃各有专属起始卡组与被动（大娃开局 +1 力量、二娃每回合多抽一张、三娃开局带格挡、四娃攻击 +15%、五娃每回合回血、六娃概率闪避、七娃开局摸宝葫芦）
- **三章闯关**：妖谷寻踪 → 峭壁救亲 → 蛇精洞府，每章 6 个节点（战斗 / 精英 / 奇遇 / 休整 / 首领）
- **救出兄弟**：击败精英与首领可救出被困的兄弟，专属卡牌加入卡组
- **七子连心**：集齐七娃立刻觉醒**金刚葫芦娃**（生命上限 +25 并回满，获得终极卡【七子连心】）
- **首领战**：蝎子精 → 金蛇卫士 → 蛇精（三阶段：如意击 / 狂暴 / 如意大泥石流）

## 🎮 操作

| 按键 | 功能 |
|:---:|:---|
| `1`~`9` | 打出手牌 |
| `E` / `空格` | 结束回合 |
| `M` | 静音 |

## 🛠️ 技术

纯 HTML5 + 原生 JS 单文件应用，零依赖、零构建、可离线游玩。WebAudio 合成音效，无外部字体/图片请求。

架构：`DATA（卡牌/敌人/事件数据）→ ENGINE（状态机 + 战斗引擎）→ UI（渲染层）`，全部通过 `window.GAME` 暴露便于测试。
