玩法说明

双塔守卫 · 角度即生命
🏹 两座固定炮塔，自动开火，你只控制炮口角度 —— 没有终点，一直守到墙塌
🎯 P1 左塔：AD 转炮口 · P2 右塔：←→ 转炮口
⬆️ 升级不暂停：卡片出现在自己 HUD 下方，W/↑ 换一张 · S/↓ 选中
⏳ 不理它也行：4.6 秒后自动替你选当前最优的一张（AI 托管的一侧 1.1 秒）
❄ 元素：点「烈焰 / 寒霜 / 雷霆附魔」，那座塔就转为 火 / 冰 / 雷；三个都没点 = 锐（暴击 +12%）。炮塔外观、弹体形状、拖尾全都会变
🤝 元素反应（真正的配合）：两塔元素不同、0.85 秒内交替打中同一只就触发 ——
　　冰 + 火 → 融化：白汽爆开，按最大血比例结算，解冻并溅射周围
　　冰 + 雷 → 超导：冻得更久，全队打它 +45% 伤害（6 秒）
　　火 + 雷 → 过载：半径 92 爆炸 + 击退，成片清场
　　锐 + 任意元素 → 破绽：该次伤害 ×1.55~2.0，纯物理高攻塔的归宿
🎯 反应强度随两边附魔等级之和上涨（双方合计 6 级 ×1.66 → 12 级 ×3.64），所以两个人都要点元素，一个人点没用
⚡ 另有合击：两塔 2 秒内打中同一只 → 受创 ×2.6；和元素反应可以叠加
🎯 箭矢微微吸附：方向大致对上了，会自己拐一点点去咬住目标
🔒 升级有律：第一次点哪系元素就锁定哪系 —— 之后卡坞只弹本系（另一系永远消失），本系每轮保底一张；弹道颜色/形状从一而终，不会再"点了冰弹出来却是火球"
💥 击杀累积连击，连击越高射速越快；双塔伤害共同充能共鸣槽，满了自动放双子贯穿光束 —— 光束实时跟随炮口，A/D 指哪照哪，命中附带各自元素效果
🤖 某一边 5 秒无操作 → 那一边自动 AI 托管，一动就抢回
⚔️ 处决：空格（P1）/ 小键盘 Enter（P2），12 秒冷却，炮口前方 90° 扇形内全体 ×3 伤害 + 重击退；扇形里没敌人时不扣冷却；选处决强化卡可升到 ×7.5 / 6 秒冷却
✨ 词缀精英：金色描边、体积更大、血更厚。词缀 = 分裂 / 护盾 / 加速 / 吸血 / 死亡爆炸，每只随机 1~2 条，越往后来得越多 —— 优先点掉它们
⚠️ 突发危机：兽潮 / 史莱姆王 / 酸雨 / 暗夜 / 狂暴 / 重甲突袭，越往后来得越勤
