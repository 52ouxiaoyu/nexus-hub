# 🏰 奇幻守卫战：胖王保卫纪 (v2.0.0)

这是一款结合了《王国保卫战》奇幻背景与《保卫萝卜》Q萌画风的全新防守游戏！

## 🌟 v2.0.0 更新亮点：全新混合式 UI (Hybrid UI)
- **玻璃拟物风 (Glassmorphism)**：全新的 HTML/CSS 悬浮 UI，带来清透现代的视觉体验。
- **动态物理反馈**：当胖王的城堡受到攻击时，生命值 UI 会产生真实的剧烈震动和红光警报！
- **性能解放**：抛弃了传统的 Canvas 文本渲染，将满屏弹幕的渲染压力与 UI 排版分离，实现丝滑 60 帧体验！
- **实时卡片**：加入了带悬浮特效的玩家卡片，实时无延迟更新金币、得分和各项战斗属性。

## 🎯 游戏玩法
- **多人合作**：支持 1 到 3 名玩家共同防守！
- **动态路线**：敌人可以从 1 到 5 条路线发起进攻，你可以在开始菜单自由配置难度！
- **自动升级**：有了足够的金币，系统会自动为你购买当前最划算的属性升级（攻击力、射速、多重箭）。
- **技能道具**：击杀敌人会掉落各种神奇道具（炸弹、冰冻、宝箱），射中道具即可全屏释放技能。
- **最后防线**：保护底部的城堡，胖王的血量降为 0 即游戏失败！

## 🕹️ 操作说明
在主菜单调整好**玩家人数**和**敌人路线**后点击开始：
- **玩家 1 (金色将军)**：`A` / `D` 键
- **玩家 2 (青色将军)**：`⬅️` / `➡️` 方向键
- **玩家 3 (紫色将军)**：`J` / `L` 键

## 🚀 立即体验
直接使用浏览器打开 `index.html` 开始游戏！
