# Nexus Hub (综合娱乐学习大厅) 🌌 v1.1.0

> **最新更新 (v1.1.0)**: AI 文章跟读中心新增“每页显示句子数量”选项，并支持自由跳过严格通关模式。

这是一个充满复古乐趣与现代创新的综合平台！本项目不仅包含了多款由 HTML5 Canvas 和原生 JavaScript 驱动的经典网页游戏，还融合了音视频播放（TVBox）以及学习工具。支持中英文双语界面（Bilingual UI）。无需安装，点开即玩！

## 🌟 游戏列表 (Games List)

### 1. 几何大战 (Geometry Wars) 🔥 *强烈推荐*
一款支持双人合作（Co-op）的纯正霓虹风弹幕射击游戏！
- **双摇杆独立瞄准**：完美的弹幕射击体验！P1 鼠标控制独立射击方向，P2 纯键盘实现独立走位与独立射击（IJKL 射击方向）。
- **分数倍率系统 (Geom System)**：消灭几何体会掉落专属的绿色发光晶体 (Geoms)，拾取可不断提升得分倍率。被击中或受击会清空倍率！
- **同类合体进化机制**：为了保证游戏后期画面的极致流畅度，长时间未被击杀的同类型几何体会彼此融合，体积变大，血量、弹幕密度成倍提升！
- **盲盒空投 (Loot Boxes)**：地图上随机刷新包含各种霓虹道具的宝箱，包括：武器升级、极速立场、重力护盾、甚至是全屏清场核弹！
- **AI 智能托管机制**：玩家如果超过 5 秒钟不操作，聪明的 AI 将会自动接管角色，进行风筝走位并全自动射击！玩家按任意键即可随时收回控制权。

### 2. 坦克大战 (Tank Battle)
重温红白机时代的经典回忆，保卫基地，消灭敌方坦克大军。

### 3. 贪吃蛇 (Snake)
最经典的休闲游戏，吃掉苹果让蛇变长，看看你能坚持多久不撞墙。

### 4. 三国无双射击 (Kingdom Rush)
一款支持 1-3 人同屏合作的古风割草射击游戏！
- **三国国风主题**：化身古代武将，抵御黄巾军、西凉铁骑和铁浮屠的进攻。
- **深度的武器进化系统**：在局内通过花费军饷升级武器，形态将发生质的飞跃：
  - 🏹 **1阶：长弓** (基础弓箭)
  - 🏹 **2阶：诸葛连弩** (攻速飞快的连发弩箭)
  - 🪨 **3阶：霹雳车** (发射巨大的落石，造成大范围真实AOE溅射)
  - 🪵 **4阶：八牛床弩** (发射巨型弩箭，无限穿透直线上所有敌人)
  - 🐉 **5阶：火龙出水** (发射自带智能追踪+范围爆炸的古代追踪火器)
  - 💣 **6阶：万人敌(震天雷)** (终极武器，威力绝伦的全屏核爆级清场)
- **三国名将 Boss 战**：极度强悍的名将（无双吕布、天公张角、魔王董卓）降临，且拥有智能的“左右横跳”AI避开玩家火力。
- **动态难度与经济系统**：支持1-10条独立兵线，路线越多刷怪越疯狂。敌人的血量无限成长，掉落的军饷也同步暴增！
- **丰富的奇兵道具（包含Buff与Debuff）**：击杀小兵随机掉落各种功能奇葩的道具，例如：草船借箭（全屏狂暴射击）、奇门遁甲（全员罚站）、鸩酒（扣除军饷）等。

### 5. 葫芦娃大战妖精 (Calabash Brothers)
经典的国漫 IP 塔防！种植各种葫芦娃来抵御蛇精和蝎子精的进攻。

### 6. 植物大战僵尸 (Plants vs. Zombies) 🌻 *最新重磅更新*
完美还原经典的塔防神作！极其精美的一比一复刻版。
- **战前选卡系统**：完美还原原版的 Seed Chooser 界面，玩家可以在战前从多达 24 种经典植物中自由挑选 10 种植物作为本局的手牌阵容！
- **24 种原版全陆地植物制霸**：包含了全部白天、黑夜、水池和屋顶的经典陆战植物。包括：高坚果、三线射手、大喷菇（穿透攻击）、胆小菇、寒冰菇（全屏冰冻）、毁灭菇（全屏秒杀）、机枪射手（四连发）、双子向日葵，甚至还有大蒜（逼迫僵尸换行）以及火炬树桩（点燃豌豆变成伤害翻倍的火弹）等高阶植物！
- **复杂的僵尸状态机机制**：包含普通僵尸、路障僵尸、铁桶僵尸、以及超高移速高血量的橄榄球僵尸（Football Zombie）。带有逼真的啃咬、断手、掉防具分离以及死亡动画。
- **完善的碰撞与特效系统**：精确处理了地刺的无视碰撞（不被吃）、阳光的自动收集飞入特效，并高清还原了原版所有的 UI、受击音效及 BGM。

## 🚀 如何运行 (How to Run)

本项目无需任何后端环境或构建工具（No Node.js/Webpack required）。
1. 直接在浏览器中双击打开 `index.html` 即可进入游戏大厅。
2. 也可以使用任何本地服务器运行（例如：`python -m http.server` 或 VSCode 的 Live Server 插件）。

## 💡 操作指南 (Controls)

每款游戏内都提供了详细的按键说明。大多数游戏支持使用键盘的 `W A S D` 或 `↑ ↓ ← →` 进行移动。

## 🌍 双语支持 (Bilingual)
游戏大厅以及所有的游戏界面均已实现中英双语显示，方便不同国家和地区的玩家一起享受游戏的乐趣。
