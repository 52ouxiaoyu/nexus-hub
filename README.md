## 🌟 游戏列表 (Games List)

### 1. 极速飞车 (Turbo Rush 3D) 🏎️ *全新 3D 竞速 (v1.2.3)*
基于 three.js 的低多边形 3D 环形赛道赛车。每一局都会生成一条随机蜿蜒的赛道，地形随赛道起伏，支持氮气加速、3 名 AI 对手和最佳圈速挑战，手感参考经典街机赛车游戏。
- **v1.1.0 新增**：
  - 🏁 **双人分屏 PK**：选择"双人对战"模式，屏幕左右对半分，两名玩家各自驾驶红车/蓝车同场竞技，先完成 3 圈者获胜。
  - 🛡️ **出赛道防消失**：大幅降低草地起伏、增强出赛道摩擦力与回拉力，赛车离开路面后不会整辆车消失，而是始终可见并慢慢被拉回赛道。
- **v1.1.1 修复**：A / ← 现在对应视觉左转，D / → 对应视觉右转（之前因相机坐标系导致方向相反）。
- **v1.1.2 手感优化**：
  - 🌾 **草地阻尼更接近真实**：出赛道最高速从 0.25× 路面速度放宽到 0.55×，滚动阻力从约 25× 降至 2.5×，不再有"瞬间被吸住"的失真感，同时仍然比路面慢。
  - 🪧 **路边方向指示牌**：把地面上的扁平箭头换成黑黄警示色的 V 字指示牌（立在路边、木桩支撑、朝路面微倾），前进方向一目了然。
- **v1.2.0 极简操作 + 碰撞**：
  - 🎮 **极简键位**：只需 4 个方向键（WASD 或方向键）驾驶，1 个加速键（P1 空格 / P2 回车），无刹车、无手刹——松开油门自然减速，新手 10 秒上手。
  - ⏱️ **加速带冷却**：一次加速最长 2.2 秒，用完（或中途松开）即进入 4 秒冷却，HUD 氮气条实时显示冷却恢复进度。
  - 💥 **树/岩石碰撞**：撞树、撞岩石不再穿透——车辆会被弹开并按撞击角度减速（正面撞减速 ~62%，侧刮 ~12%），伴随撞击音效。
- **v1.2.1 车对车碰撞物理重做**：
  - 🚗💥🚗 **动量守恒模型**：车与车相撞改为等质量动量交换（恢复系数 0.72），取代旧的"碰到就统一掉速"。
  - 🔄 **被追尾会向前冲**：后面的车撞你，你获得向前的动量往前冲，后车按动量减速。
  - 🎯 **撞前车**：前车被撞飞、自己稍减速——符合"我推它、它快我慢"的物理直觉。
  - 🤝 **并排挤行不骤停**：两车挤在一起但无相对接近速度时，只有轻微持续摩擦互损，不再莫名其妙瞬间掉速。
- **v1.2.2 新手抓地增强**：
  - 🛞 **过弯更容易拐住**：侧向抓地上限 19 → 26（30 m/s 过弯半径 47m → 35m，165 km/h 时 111m → 81m），大幅减少"一打方向就冲出赛道"。
  - 🎯 **转向更跟手**：方向盘最大角度加大且高速衰减放缓，高速下方向不再"发死"。
  - 🧲 **车尾更跟手**：速度方向跟随车头的速率 7.0 → 9.5，弯中甩尾/侧滑感大幅减少，轻微侧滑掉速也更低。
- **v1.2.3 氮气尾焰特效**：
  - 🔥 **加速喷火**：按住空格/回车加速时，车尾两个排气口会喷出橙黄色火焰（发光渐隐），并带少量淡灰尾烟，松开即停。
  - 🎇 **纯程序生成**：粒子纹理由 canvas 实时生成（72 个精灵粒子池循环复用），无外部素材，性能开销极小。

### 2. 几何大战 (Geometry Wars) 🔥 *强烈推荐*
一款支持双人合作（Co-op）的纯正霓虹风弹幕射击游戏！
- **双摇杆独立瞄准**：完美的弹幕射击体验！P1 鼠标控制独立射击方向，P2 纯键盘实现独立走位与独立射击（IJKL 射击方向）。
- **分数倍率系统 (Geom System)**：消灭几何体会掉落专属的绿色发光晶体 (Geoms)，拾取可不断提升得分倍率。被击中或受击会清空倍率！
- **同类合体进化机制**：为了保证游戏后期画面的极致流畅度，长时间未被击杀的同类型几何体会彼此融合，体积变大，血量、弹幕密度成倍提升！
- **盲盒空投 (Loot Boxes)**：地图上随机刷新包含各种霓虹道具的宝箱，包括：武器升级、极速立场、重力护盾、甚至是全屏清场核弹！
- **AI 智能托管机制**：玩家如果超过 5 秒钟不操作，聪明的 AI 将会自动接管角色，进行风筝走位并全自动射击！玩家按任意键即可随时收回控制权。

### 7. 植物大战僵尸 (Plants vs. Zombies) 🌻 *最新重磅更新*
完美还原经典的塔防神作！极其精美的一比一复刻版。
- **战前选卡系统**：完美还原原版的 Seed Chooser 界面，玩家可以在战前从多达 24 种经典植物中自由挑选 10 种植物作为本局的手牌阵容！

- **复杂的僵尸状态机机制**：包含普通僵尸、路障僵尸、铁桶僵尸、以及超高移速高血量的橄榄球僵尸（Football Zombie）。带有逼真的啃咬、断手、掉防具分离以及死亡动画。
- **完善的碰撞与特效系统**：精确处理了地刺的无视碰撞（不被吃）、阳光的自动收集飞入特效，并高清还原了原版所有的 UI、受击音效及 BGM。
- **🎨 西瓜投手 / 冰西瓜投手原版化外观**：木制碗形投石车底座 + 完整圆西瓜造型，发射的子弹也是完整圆西瓜（不再是被 CSS 滤镜染色的切片）。普通冒险模式与融合进化模式（含西瓜猫尾草、冰西瓜猫尾草）均已生效。
- **🏷️ 游戏内版本号徽标**：游戏界面右上角实时显示当前版本号（如 `v3.2.0-melon (build 2026-08-30)`），鼠标悬停可查看改动说明。配合 `bump_version.py` 脚本可一键更新版本号与缓存刷新参数。

> **开发者提示**：修改 PVZ 代码或素材后，运行 `python3 bump_version.py "v3.x.y-描述"` 即可自动更新 `pvz-web/version.json` 并刷新所有 `?v=` 缓存参数，然后 `git commit && git push`。玩家只需硬刷新（Cmd+Shift+R）即可加载新版本。

## 🚀 如何运行 (How to Run)

本项目无需任何后端环境或构建工具（No Node.js/Webpack required）。
1. 直接在浏览器中双击打开 `index.html` 即可进入游戏大厅。
2. 也可以使用任何本地服务器运行（例如：`python -m http.server` 或 VSCode 的 Live Server 插件）。

## 💡 操作指南 (Controls)

每款游戏内都提供了详细的按键说明。大多数游戏支持使用键盘的 `W A S D` 或 `↑ ↓ ← →` 进行移动。
