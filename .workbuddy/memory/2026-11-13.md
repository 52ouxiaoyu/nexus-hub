## pvz-web v4.0.157 — 机械龙改植物体系 + 泡泡牧场顶替经典泡泡龙

commit `eba6577`，已推 origin/main。

### 用户给的原规则（逐条落地）
- 3 个豌豆 = 5 点；4 个 = 双发 10 点；机枪 = **连续 4 次消除**（用户确认）→ 40 点
- 寒冰：伤害减半，消除数 = 霜冻层数；满 6 层冰封 3 秒；**连续 5 回合没人消 → 全场寒冰融回豌豆**
- 玉米：每消 3 颗掷 25% 黄油 → 定身 10 秒
- 小喷菇 3 连毒 1/回合×10；大喷菇 4 连 2；忧郁菇 5 连 4 + 血上限顶到 1000
- 「机箱」= 机枪豌豆 Gatling Pea（用户语音输入错字，已确认）
- 一回合 = 打出一颗球；毒在下一回合开头结算

### 关键工程设计
- **同色 = 同种植物**。不新增颜色（仍是 4 色），由「消除数量 n」决定进化形态：
  绿 `5*(n-2)`、紫 `[0,1,2,4,8][n-2]`、黄 `5*(n-2)` + 25%/3颗、蓝 `round(5*(n-2)*0.5)` + frost。
  这样 8 种植物的描述全部塞进 4 色网格，不用把 nColors 加到 8（加到 8 会稀释同色概率，三消直接玩不动）。
- **状态线必须互相加成**才有策略：黄油期受伤 +50%、冰封期翻倍、毒不吃这两个加成（持续伤不跟爆发）。
- 忧郁菇是「激怒换爆发」：血上限 640→1000 且当前血 +360，但毒 4 倍。300 局模拟 63% 会触发。

### 踩的坑（都是肉眼才发现，断言查不出）
1. **画布是 900×600，不是 700**。牧场花盆按 700 排版 → 整排被底边切掉。布局必须先把 W/H 读出来。
2. **DOM 顶栏（回大厅/关卡名/声音）压在画布 0~52px 上**。血条从 x=250 起、阶段文字右对齐 244 → 被按钮吃掉一半。
   现在机械龙 HUD 全在 330~620 中间带；牧场 HUD 从 y=68 起。
3. **黄油斑块第一版画在 y=56~134**，正好在血条和状态条底下 → 玩家永远看不见。下移到龙的下颌/躯干（y=132~180）。
4. **SFX.pop 在 `BubLane.land()` 里，不在 `settle()` 里**。测试直接调 settle 断言"有碎裂声"必然失败，要构造真实 `land()`。
5. **机器人测平衡会骗人**：瞄准"最低行的中间球"会一直打同一列，形成 `[19,18,12,1,1,1,1,1,1]` 这种一字长蛇，7 发就顶到红线，0 伤害。
   真正可信的是**数学模拟**：直接调 `onPop` 按真实三消分布（3~6 连、4 色均分、25% 空发）跑 300 局。

### 平衡结论（重要）
- 伤害从旧版「4 点/颗」换成植物体系后**整体低 40%**，同样的喷吐节奏会让玩家先被压死
  （机器人 32 秒只打掉 117/640 血）。
- 解法不是加伤害（用户给了明确数值），而是**放慢下压**：喷吐间隔 6.6/5.0/4.0 → 8.2/6.4/5.2，每次少压 1 颗（5/6/7 → 4/5/6）。
- 调完：中位 37 回合 / 平均 39 回合 ≈ 2 分钟，298/300 可击杀。

### 泡泡牧场（新玩法）
- 5 个花盆绑 4 色（第 5 盆也是绿，保证一局能养满两盆绿）。
- 同色喂满 3 颗升 1 级，6 级链：豌豆→双发→机枪→寒冰→玉米→西瓜；养出 **2 盆满级**通关。
- 清空场地不算赢（`lane.noClear`），每次升级 `pushCeil(2)` 惩罚（越强越危险）。
- 满级作物自己打：Lv6 一次带走整簇同色 + 溅射，Lv4+ 有 40% 额外一颗。
- 植物攻击**不给种子**（否则滚雪球）。

## v4.0.158 砸罐子加难 + 倍速文案统一（用户三条要求）

用户原话：①砸罐子太简单了 ②倍速显示中英混杂（1 是中文、点一下变英文且回不去）③植物不要这么多、要以问号罐为主。

### ① 配比翻过来（可量化的改法）
- 先写 `_measure_vase.js` 量基线，再定目标，别靠感觉：旧版自由局简单档绿罐 **51%**、问号 22%。
- 两处「真正的开关」：
  - 自由局 = `_vaseDiffCfg()` 的 `plantMin/plantMax`（硬夹子，`setupVases` 会按它强制校准绿罐数量）+ `bag` 抽签桶；
  - 手工关 = `VASE_LEVELS` 的 `p/q/z` 配额（写死，校准逻辑对关卡一律跳过）。
- 结果：绿罐 51%/33%/8% → 25%/17%/6%；十关绿罐 9~13 → 4~5，问号 8~12（46%~59%）；十关植物 129 → **110 株**，血量 0.90→1.08 爬坡。

### ② 「问号罐为主」与「僵尸贴脸」的死结 —— 换位置不换内容
- 问号罐按 v3.41.0 钉在前中排，让它开僵尸 = 前排 col1~3 刷僵尸 = 必死（玩家判断不出、还必须砸完所有罐才能过关）。
- 先试了「前后排问号罐**内容**对调」→ 后排问号罐平均只剩 0.2~0.35 个，压根没目标，等于没改（且把僵尸塞进绿罐会打破「绿罐=植物/阳光」的视觉承诺）。
- 正解：**交换罐子位置**。问号罐彼此长得一模一样，换位零痕迹；绿罐照样是绿罐。
  目标优先后排问号罐 → 后排绿罐 → 后排僵尸罐（把明牌挪前、暗雷挪后），每局最多前移 1 个僵尸罐，
  再不行就把这颗暗雷直接摊成植物。
- **判据要分红牌/暗雷**：僵尸罐有红光脉动 + 玩家可以选择「先不砸、先布防」，那是紧张感；
  问号罐/绿罐在前排吐僵尸才是暗雷。断言就该这么写（`frontHidden===0`、`frontVisible` 只做上限）。
- 顺带修死局：大蒜系把僵尸顶进**第 0 行**（砸罐子 candidates 从 r=1 起，第 0 行永远没罐子也没植物），
  第 8 关因此恒败。`adjRowOf`/`_garlicHits` 两处 `minRow` 在 `vaseMode` 下锁 1。

### ③ 倍速文案：单一写入点
- 病根：HTML 初始是「倍速: 1x」，点击 handler 里硬写 `Speed: Nx` → 第一次点击就变英文且永不回头。
- 改成 `cycleGameSpeed()` + `_syncSpeedLabel()` 唯一写入点。
- 顺带：「时光」事件 `g.gameSpeed=4; setTimeout(()=>g.gameSpeed=1)` 会把玩家选的倍速吃掉 → 存 `prev` 还原。
- 验收里这条一开始被静默跳过：`g.eventManager` 是 `update()` 里懒创建的，主菜单阶段 undefined → 断言里 `new EventManager(g)` 自己造一个。

### ④ 机器人测平衡：这一版踩了 4 个坑（重要）
机器人恒输 ≠ 关卡不可解。按踩坑顺序：
1. 给「有罐子但**没有僵尸**的行」也发输出（第 5 关第 4 行只有绿罐+阳光，白扔一株）→ 首轮只铺有僵尸的行。
2. `plantAt(row, atkTypes.shift(), …)` **先吃卡再试种** → 种不下这张卡就凭空消失；且失败即 `break` 整轮 → 改成 `atkTypes[0]` 试种成功才 shift、按优先级遍历所有行。
3. 只数「几只僵尸」不数「多硬」→ 一行 1 只路障（538 血）和一行 0 只同权重。
4. 最终采用「有僵尸的行先各 1 株、再各补第 2 株、剩下按 `rowZ - atk*1.6` 倾斜」——最接近真人。
- 判死之前**必须 dump 出罐位置**（wrap `_revealZombieFromVase` 记 `type@r?c?[罐型]`）+ 棋盘 `grid`。
  这一版就靠 dump 才看清：① 掉壳后 `this.type='normal'`（Zombie.js 1174~1221）会把路障误读成「凭空出现的普通僵尸」；
  ② 崩盘那行根本一株植物都没有。

### ⑤ 顺手修的残留 bug
- `_renderVaseLevels` 用 `lv.diff` 取难度配色，但 v4.0.150 起字段改叫 `lvl` → 十张卡全是 `diff-undefined`（CSS 只定义了 `.vlm-cell.diff-hard/.diff-hell`），一个颜色。用 `_startVaseLevel` 同款映射补回。
