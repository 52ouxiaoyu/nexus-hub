## v3.6.1 冰西瓜卡面冰蓝背景改为草地绿（已 push 89ae6f5）

**用户反馈**：冰西瓜的背景画面不要是蓝色的，请把它改成绿色，跟其他植物一样。

- 实测 3662 像素重写，主色 `#48b8d8` → `#68d848`（草地绿）
- 深蓝瓜主体（暗色 R+G+B 偏低）+ 下半灰度种子图标完全保留

## v3.6.3 冰西瓜卡面背景换西瓜投手草地，造型不动（已 push 6d7f972）

**用户反馈**：只要把背景换成西瓜投手的背景，主体不动。不需要改变冰西瓜投手的造型，只需要改动它的背景即可。

**根因（前两轮失败）**：
- v3.6.1 HSV 染绿按颜色范围改写 → 误伤冰瓜高光/冰霜（与雪地同色系）
- 单纯 hue-rotate / 按颜色范围替换 → 无法区分"底色"和"本体"（冰瓜本身也是冰蓝调）

**正确算法（同模板逐像素合成）**：PVZ1 中 WinterMelon 与 MelonPult 卡面是**同构图改色**（左上方大瓜+右前方抛投小瓜+地面），两张图每个像素 (x,y) 在视觉上"背景区"与"造型区"位置完全重合。
```
对 WinterMelon 上半 60px 每个像素:
  若 WinterMelon(x,y) 是雪地蓝 (色距 #4ab2d3 ≤ 50):
    若 MelonPult(x,y) 同位置是草地绿 (色距 #08c828 ≤ 50):
        → 替换为 MelonPult 同位置像素 (真正的背景区, 3095 像素)
    否则:
        → 保留 WinterMelon 原值 (MelonPult 同位置是瓜/台座/暗影 → 保护本体, 632 像素)
  否则:
    → 保留 WinterMelon 原值 (WinterMelon 本身就不是雪地 → 本体/暗影/叶, 1892 像素)
```

**结果**：
- 草地绿 #08c828 进入 3016 像素（背景区）
- 冰瓜暗蓝 #185888/#186898 像素数与 v3.6.2 完全一致（造型未动）
- 投石器轮廓蓝 #2878a8 保留
- 14.9% 蓝残留 = 冰瓜本体 + 冰霜 + 投石器（冰调保留）

**验证**（/tmp/v363_verify.js）：
- T1 URL 含新 ?v= 戳 ✓
- T2 WinterMelon 卡上半绿像素 56.9%（v3.6.2 仅 2%） ✓
- T3 冰蓝雪地残留 14.9%（v3.6.2 是 70%，大幅减少） ✓
- T4 冰瓜本体暗蓝 14.4% 保留 ✓
- T5 MelonPult 对照卡仍 63% 绿（未受影响） ✓
- T6 0 pageerror ✓

**教训（重大）**：
- "底色与本体同色系"的素材（冰蓝底+冰蓝瓜），**按颜色范围改色必翻车**——需要"构图对照"作参照
- PVZ1 同系列卡面（冰瓜/西瓜、雪人/普通巨人、坚果/高坚果）常为**同模板改色**，是天然的"背景/造型分离"参照；用构图对照图(本例 MelonPult)定义背景蒙版 + 双色判别双侧验证，才能安全合成
