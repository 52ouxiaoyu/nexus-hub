### 机制一：破甲（仅限这两株投手）
投掷物**越过路障 / 铁桶 / 报纸 / 铁门直接打僵尸本体，护甲外观永不脱落**——僵尸顶着路障被活活打死。
- 实现：僵尸新增 `armorHp` 双血池。`hp` 仍是总血量；`armorHp` 只记录"护甲能感知到的伤害"。
  破甲伤害只扣 `hp`、不扣 `armorHp`，于是脱落判定（阈值 200/150）永不触发。
- 向后兼容：非破甲伤害两池同扣 → 旧行为逐字节不变；`armorHp === null` 守卫兼容旧调用。
- 冰车僵尸（zomboni）无装甲概念，按普通僵尸血量算。

### 机制二：黄油定身
命中后僵尸 **3 秒一步不动、一口不啃**（`update()` 早返回，连巨人秒砸也停）。
- 独立于寒冰减速（`slowTimer`），两者可共存；状态滤镜**黄油黄优先于寒冰蓝**。
- 重复命中只刷新时长、不累加；定身期间仍可被其它伤害打死。

## 调试中踩到的两个"假失败"（重要）
1. **`setupZombieEnemies()` 只在空格子落子**：测"我是僵尸敌阵抽签池"时若不清棋盘，第 2 次起
   `addPlant` 全部失败 → 永远只统计到同一张棋盘，表现为 0/60 或相同直方图（看似 RNG 被固定）。
   正确做法：每轮按 `GameLoop.restartZombieLevel()` 的方式清 `board.grid` + `entities`。
2. **`console` 的 404 文本不含 URL**：白名单无法按 URL 过滤，必须用 `page.on('response'/'requestfailed')` 收集 URL 再判定。
