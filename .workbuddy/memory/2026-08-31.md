
### 第三十三轮：炸弹植物作为可重复融合母体（v3.2.31-bombhost）
- **用户**：樱桃炸弹/毁灭菇/寒冰菇/火爆辣椒是"转瞬即逝"植物，无法与别的植物融合。改：攻击方式不变，可种在空地作为融合中心，3×3 范围内多次合成。
- **现有机制理解**（通过 grep + read Plant.js / GameLoop.js / InputManager.js）：
  - 炸弹 update() 自动倒数 explodeTimer 1 秒后爆炸（triggerBombFusion + 伤害 + 死亡）→ 没法当融合母体
  - triggerBombFusion 展开 3×3 只对 cherrybomb/iceshroom，**doomshroom/jalapeno 没 3×3**（bug）
  - getFusionResult 缺少 peashooter+cherrybomb→fusion_cherrybomb_peashooter 和 sunflower+doomshroom→fusion_doomshroom_sunflower 配方（Plant.js 275-282 视觉代码已存在但配方面板 recipes 300-301 行有显示，getFusionResult 无触发）
  - tryPlanting 的"炸弹种在植物上"是残留半成品：只设 `plant.fusionTarget=existingPlant` 但**从未被读取使用**（grep 全仓库只一处赋值），炸弹悬在植物上等 1 秒后爆炸
- **新机制**：
  1. **Plant.js**：
     - constructor 加 `isBombHost = ['cherrybomb','jalapeno','iceshroom','doomshroom'].includes(type) && !type.startsWith('fusion_')`
     - update 三个炸弹分支加 `&& !this.isBombHost` 守卫（母体待命不自动爆）
     - 抽 `explodeNow()` 方法（封装三个分支原爆炸逻辑，复制粘贴）—— 点击引爆
     - triggerBombFusion 展开 3×3 加上 doomshroom + jalapeno
  2. **GameLoop.tryGloveInteraction**：在普通融合前加炸弹母体分支（|Δrow|≤1 && |Δcol|≤1 = 3×3 切比雪夫距离含对角）：
     - host=isBombHost 那个（炸弹）、victim=另一个
     - 炸弹**保留**、victim 消耗、产物生成在 victim 位置
     - **保持 isGloveActive=true**、仅清 gloveSource → 玩家可继续点下一个 3×3 植物反复合成（"多次合成"核心 UX）
     - 超出 3×3 提示"炸弹只能与周围 3×3 范围内的植物合成"
  3. **GameLoop.getFusionResult**：补两条配方（peashooter+cherrybomb→fusion_cherrybomb_peashooter 樱桃射手、sunflower+doomshroom→fusion_doomshroom_sunflower 毁灭向日葵）
  4. **GameLoop.tryPlanting 炸弹种在植物上**：改为**立即融合**（有配方→生成产物；无配方→提示退还阳光）。种空地时 isBomb 加 showAnnouncement("炸弹已就位！点击引爆，或用手套与周围 3×3 内植物多次合成")
  5. **InputManager.mouseup else 分支**：普通点击（非手套/种子/铲子）→ grid 植物若 isBombHost → plant.explodeNow() 引爆

- **关键经验**：
  - **"转瞬即逝"植物当母体的模式**：isBombHost flag + explodeNow() 抽方法 + update 守卫 + 3×3 母体融合分支（host保留/victim消耗/glove 保持激活）
  - **多次合成的 UX 关键**：融合后**保持 isGloveActive=true** + **只清 gloveSource**，玩家连续点 3×3 内不同植物反复合成
  - **3×3 范围判定**：切比雪夫距离 `|Δrow|≤1 && |Δcol|≤1`（含对角线），不是曼哈顿
  - **抽出 explodeNow()**：原逻辑复制粘贴到新方法（不调 update 分支，因为 isBombHost 时分支不执行）—— 简单直接，比抽象更清晰
  - **Plant.js trait 系统**：hasTrait 查 type 或 traits 数组；融合植物 traits=[p1, p2]，isBombHost 只对非 fusion_ 基础炸弹为 true（融合炸弹仍是消耗型）
  - **历史 bug**：fusion_frostbomb 死亡分支（354-377）会在 hp=0 时再放 Boom + 1800 伤害，导致樱桃射手双重爆炸（原 bug，不在本次范围未修）
  - **测试脚本的冷却陷阱**：tryPlanting 检查 cooldowns，多次种同植物需 `g.cooldowns = {}` 清零
