## 语文专项学习（chinese-blitz/）· v1.0.0 上线

**来源**：github.com/52ouxiaoyu/Chinese_study —— FastAPI + SQLite 全栈「高考语文死磕通关作战系统」
（8 大工作台 / 21 个 REST 接口 / engine.py 599 行算法）。CF Pages 跑不了 Python，故做**纯静态移植**（用户选定方案）。

**交付结构**（nexus-hub/chinese-blitz/）
- `data/seed.js`：SQLite 11 张表全量导出为 `window.__CB_SEED__ = {tables, seq}`（123KB）
- `js/api-shim.js`：移植 engine.py 全部算法（认知门禁 / 1-2-7-15 状态机 / 三维采分解剖 / 作文 3:7 叙议比 Linter）
  + 21 个接口路由，**覆写 window.fetch 拦截 `/api/*`**，返回真 `Response`；状态存 `localStorage[chinese_blitz_state_v1]`
  → 前端 app.js 零改动即可跑。`window.cbResetAll()` 重置；`window.__CB_DB__` / `__CB_ENGINE__` 供测试
- `index.html` / `js/app.js` / `css/styles.css`：来自上游，只改资源路径（`/static/` → 相对）
- 入口：learning.html 新增「语文专项学习」卡片

**上游遗留缺陷（本次顺手修）**：数据里 module_code 是**裸码**（`POETRY`/`DICTATION`），而前端多处写死 `MOD_` 前缀
→ 下拉筛选永远空列表、轨迹表各板块恒 `--`；另 `实词/虚词/古今异义` 与 `REAL_WORD/FUNC_WORD/ANCIENT_MODERN`、
`LAYER1_CORE_PERSON` 与 `ANCIENT/MODERN/CONTEMPORARY/ONE_LINER` 也不匹配。修法：统一成数据真实编码
（index.html 下拉 value + app.js 7 处 `MOD_` + shim 的 ROI 系数表兼容两种写法）。词条枚举另加中文标签
`word_type_label/freq_tier_label`。

**验证**：`/tmp/cb_test.js`（puppeteer + `python3 -m http.server 8901`）47 项断言全 PASS ——
渲染件数、8 Tab、按模块筛题、三维解剖、认知门禁拦截「粗心」、合规卡片入库、1-2-7-15 晋级、坑库 +1、

3 套 A4 模板、刷新后 localStorage 持久化、无 JS 报错 / 无 404。

**铁律记录**：静态版不写本地 Excel（`excel_sync.synced=false`）；进度只在本设备，
