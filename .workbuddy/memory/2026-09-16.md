## racing-3d v1.2.7 · 抓地再增强 + 草地惩罚（抄近路亏本）

用户反馈：150 码左右还是容易甩到草地；且草地抄近路反而比走赛道快（绕近路+草地不够慢）。

定量评估（puppeteer 实测 world.smp[].curv）：
- 赛道全长 ~1458m，最急 1% 弯半径 26m、5% <44.5m、10% <62m、20% <98m
- 旧 LAT_GRIP=26：150 km/h 最小拐弯半径 = v²/GRIP = 67m → 最急 5~10% 弯全速拐不住（用户感觉不是错觉）
- 旧草地：极速 0.55×46≈91 km/h + 滚阻仅 2.5× → 抄近路净赚

改法：
- LAT_GRIP 26 → 36（150 码半径 67→42m，实测 42.2m；165 极速可拐 58m）
- 路面 gripRate 9.5 → 11（侧滑角 0.134 rad，车尾贴线）
- 草地：vmaxEff 0.55→0.40、滚阻 0.030→0.055（4.6×）、新增 CFG.GRASS_GRIP=0.65
  （latCap 与 gripRate 都按 onRoad 打折；gripRate 草地 7）

T27 测试 5 项，96/96。T27 调试两轮的教训：
- **满舵转圈测试会被赛道几何污染**：车转圈会离开/回到 8.3m 路宽，onRoad 在测量
  窗口内翻转 → 路面/草地数据都失真（0.97 vs 0.88 甚至倒挂）。修法：短窗口
  （0.19s，路面组横摆 <5m）+ 低速（20 m/s，弯转半径 11m）+ 草地组摆 smp+left*40
- **满舵长窗口测"150码半径"时车会出路面**，实测 42.2m 反而是混合值——但方向正确，
  断言 ≤52m 稳过。要纯路面值得用短窗口
- python 替换 heredoc 里两处 replace 时，第二处 assert 失败会让整个文件不写

## racing-3d v1.3.0 · 路面加宽 + 草地惩罚渐变化

用户反馈：① 还是容易甩出路面（路是不是太窄）；② 草地上"完全吸住一动不动，然后一下子移到前面去"。

② 根因（代码复盘坐实）：路缘是硬悬崖——|lat| 过 9.8m 瞬间 vmaxEff 46→18.4、
滚阻/抓地瞬间切换。出弯蹭出路缘 → 油门公式 (1-v/vmaxEff) 瞬间归零+限速压
7m/s²，体感"被吸住"；回到路面 → vmaxEff 跳回 46，油门瞬间满额，体感"弹射前窜"。
（次要因素：nearestIdx 在赛道相邻段 <40m 处可能 snap 到错误段，拖拽方向错乱——
本次未动，若再复现查这里）

修复：
- ROAD_HALF 7→8.5（路宽 14→17m）；全部派生尺寸自动适配（立柱 span、看台、
  指示牌、树石间距、AI laneT、checkGate 门宽），无需单独改
- 草地惩罚渐变化：off=clamp((|lat|-edge)/5,0,1)，vmaxEff×(1-0.6off)、
  滚阻 0.012+0.043off、抓地×(1-0.35off)、gripRate 11-4off、相机颠簸×off
- 深草数值与 v1.2.7 一致（off=1），抄近路仍亏本

数值型距离场（off 渐变）才是正解。**
