## v4.0.152 三个新泡泡玩法上线（提交 73cf3ab，已 push）

用户要求：先造方案 A 放进小游戏 —— 删「植物消消乐」换 A、换「豌豆射击场」为 B、删「植物贪吃蛇」换 C。

### 架构：抽出 `BubLane` 内核（关键决定）
六边形泡泡场地的一整套东西抽成可复用类，三个玩法只写规则层：
```
new BubLane({ R, COLS, LEFT, TOP, rows, sx, sy, deadline, nColors,
              fillRows, gapEvery, ceilRows, missPush, missLimit })
```
方法：`aimLimit() / aimAt() / nudge() / fire() / advance() / update() / land() /
findCell() / cluster() / settle() / removeCells() / clearTombsNear() /
dropFloating() / pushCeil() / burst() / wipeColor() / wipeRow() / colorNear() /
draw() / drawAim() / bub() / tomb() / spBall()`。
钩子：`onLand(lane,res) / onClear / onDead / onSpecial / pickNext`。
**意义**：三份网格逻辑如果各写一遍必然走偏（v4.0.151 的幽灵球就是单份里踩的坑），
共用内核后判负、下压、掉落只可能错一次。

### 三个玩法
- **A 机械龙攻城** `DragonRaid`：`noClear=true`（清空场地不算赢）。龙 640 血，
  消 1 颗 = 尖刺 +4 伤害；70%/35% 两道血线推阶段（2 阶段丢护甲、喷吐 6.6→5.0s 并丢墓碑；
  3 阶段眼睛泛红、4.0s 一次、两块墓碑）。`TOMB=99` 不可同色消，只能被贴着它的爆破带走。
- **B 泡泡对轰** `BubbleDuel`：左右两块 9 列场地。消 4/6/8 颗 → 给对面顶行塞 1/2/3 块墓碑，
  悬空掉落 ≥5 再 +1。开局 AI 代打右侧（1.55~2.45s 一发），按方向键立即接管。
- **C 泡泡塔** `BubbleTower`：8 层，`loadFloor(n)` 每层重铺；第 2/4/6 层解锁
  炸弹球 `burst(R*2.15)` / 彩虹球 `wipeColor` / 闪电球 `wipeRow`，概率 10%→22%。
  连击 ≥3 有倍率。

### 踩坑

1. **判负线永远摸不到**：`deadline` 必须落在「最后一行球心 + R」附近。
   原先 dragon 写 532 而最后一行球心 553.8+R24=577.8、炮口 sy=556 → 压到底也不会触发判负。
   三个场地重排后 deadline 分别 510 / 480 / 532。
2. **误删 `LEVELS`**：用「段落标题 → 下一个 class」做切片替换，把夹在中间的
   `const LEVELS = [...]`（属于第 7 节推箱子）整块吃掉 → `LEVELS is not defined`。
   教训：**按段落切片时先确认这段里有没有属于下一节的常量**；改完立刻 `node --check` + 打开全部 10 个玩法。
3. **机器人 16 发就死**（不是平衡问题，是测试脚本问题）：机器人挑「剩余空间最多」的格子，
   却不知道那条射线被别的球挡着 → 球中途挂住，自己堆塔。加 `clearPath()` 沿射线步进 8px 判遮挡后 100% 通关。
4. **验证脚本「可玩区」要排除最后一行**：最后一行有球就已经输了，
   把它算进可达性会让 6/2/2/12 格「超界」的假 FAIL。
5. **阶段断言**：`hp = hpMax*0.75` 四舍五入后仍 > 0.7，`hurt(1)` 才越线；
   测试里直接设 `0.72 / 0.40` 更稳。
6. **居中飘字必然压东西**：泡泡塔炮台在正中央（x=450），任何 `center` 对齐的
   `连击 xN` 都会盖住炮口球或发射茎。改成底部左侧 `x=196, y=562` 的药丸（暗底 + 半透明金字）。
   同理「特殊球」图例标签要留 20px 间距，否则被第一颗图标压住。
7. **炸弹球画成黑洞**：`#3a3a36` 纯色圆环看不出体积。要径向渐变（`#928e83 → #55524b → #22221d`）
   + 橙红 `#e0653a` 边 + 左上镜面高光椭圆 + 顶部铁盖 + 火花径向光，才读得出「炸弹」。
