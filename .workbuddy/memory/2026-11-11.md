# 2026-11-11

## pvz-web v4.0.156 —— 泡泡工坊整套音效 + 机械龙嚎叫

用户要求：给泡泡工坊加声音（点名要「泡泡碎裂」和「泡泡粘合」），打龙关卡加龙哀嚎/嚎叫，再自己想些声音别让游戏干燥。

### 关键判断：没搬 mp3，改用 WebAudio 纯合成
`assets/audio/` 有 59 个原版音效，但**没有泡泡、没有机械龙**。硬塞 zombie groan 跟钢铁龙完全不搭（这是机械龙，不是丧尸）。所以内置了一个 `SFX` 合成引擎：零素材、零加载、可参数化。这是「保真优先」在缺素材时的正确解法——不是拿近似素材凑，而是合成一个不违和的。

### 两套音色必须刻意分开（这是可听性的一半）
- **泡泡/玻璃**：中高频 + 气声。发射「噗啾」(250→640Hz + 带通噪声)、粘合「啵哒」(205→92Hz 塌陷 + 60ms 膜张力)、碎裂「噼」+ 2~5 个随机玻璃叮（**消得越多整体音高越高、叮得越多**）、掉落往下漏气、下压齿轮咬合。
- **机械龙**：低频锯齿 + 颤音 + 金属噪声。受伤低吼（音高每次随机，连打像连挨咬）、护甲断裂（4 根失谐三角波 + 大铁砸地）、暴怒长吼 1.5s（双层失谐 + 颤音深度 26→46 渐深）、吸气上扫、火柱呼啸、**死亡哀嚎 2.6s 从 430Hz 塌到 33Hz**（颤音越后面越抖 + 结尾方波断电）。

### 技术要点（可复用）
- **「像活物的嗓子」靠 growl()**：锯齿 + 低通 + **LFO 接到 `oscillator.frequency`**。纯 sine 滑音听感是汽笛；加 4~7Hz 颤音 + depth 渐深才像在叫。这是本次唯一必须手写的音频知识。
- **`f0→f1` 必须用 `exponentialRampToValueAtTime`**，线性 ramp 在低频段听不出「滑」。
- **节流是音效系统的必需品**：一帧连锁消 20 颗球会叠 20 层噼啪糊成噪声。每个音效名一个 `gate[name] = performance.now()`，间隔 30~90ms（发射 38 / 粘合 34 / 碎裂 32 / 下压 220 / 警报 1500）。
- **AudioContext 必须在真实用户手势后建**：headless 测试里 `page.evaluate(()=>el.click())` 不算手势 → 必须 `page.mouse.click()`。加 `--autoplay-policy=no-user-gesture-required` 也不能省，因为 `resume()` 时机影响首帧。
- **静音用总线 gain 归零**，不是拦调用——恢复时不丢状态、也不会漏掉正在响的音。
- 对轰 AI 那侧给 `lane.sfxK = 0.3`（BubLane 的 `sfxK` 会乘进每个音量），两边一起响会抢耳朵。

### 合成音效怎么验证（没有截图可用）
挂 `AnalyserNode` 在总线上，`getFloatTimeDomainData` 量 RMS/峰值：
```js
S.probe = () => { /* analyser → rms, peak */ }
```
实测碎裂 0.068 / 粘合 0.070 / 发射 0.050 / 哀嚎 0.7s 后仍有 0.037 → 证明「真出声」且长音真的有长度。静音后 rms 归零。
**坑**：第一次 `probe()` 时 analyser 刚建出来没有历史采样，读到全 0 → 必须先空跑一次预热 120ms。

### 踩到的坑
- **静音按钮放左边压住龙关卡血条标题**：`.mini-top` 里跟「回大厅」并排 → 盖住「机械龙 · 第 3 阶段」。改到右上角跟游戏名一排才对（截图肉眼发现，断言查不出这种遮挡）。
- 寒冰推箱第一版判「有没有推箱子」写成 `this.px !== nx - dx`，此时 px 已赋值成 nx → 恒 true。要先存 `pushed` 标志再赋值。
- 寒冰推箱通关是手写 `this.over=true; this.win=true`，绕过了 `Base.end()` → 没通关音。改成 `this.end(true)`。
- Sokoban 的 `SFX.box(ok)` 用「推到目标点 vs 空推」区分音高，比单一声好。
