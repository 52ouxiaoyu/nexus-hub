# 2026-10-25 工作日志

## pvz-web v4.0.115 守屋「僵尸模式」尸潮不再咬玩家本体 + 令旗目标去掉「你」
- 用户原文：「在首乌大作战模式的僵尸模式里，我的身份也像是一个植物，因为他们都有意识地来打我，但是打又没伤害，请不要有这个举动。然后，在这个目标里面取消掉你这个称谓。如果尸潮开始，小鬼和巨人僵尸就会随机性地到那些有植物的房间，吃他们的坚果。」
- **根因 1（命令直通）**：`_cycleCommandTarget()` 候选 = `[...ais, P2].unshift(this.player)`，首次按 G 时 `indexOf(null) = -1` → 取 `candidates[0]` = **玩家自己**，令旗直接指向本体、HUD 显示「⚑ 目标:你」，`_updateZombies` 里 `zb.lockedTarget = this.commandTarget` 让小怪/巨人全员冲向他
- **根因 2（索敌池）**：僵尸索敌三处都把 allPlayers 里 `isZombie` 的玩家算作猎物 —— ① outdoors 220px 优先锁定 ② 2.5s 综合评分 ③ `if (!closestTarget) closestTarget = this.player` 兜底
- **为什么「打又没伤害」**：接触伤害处早有 `if (p.isZombie) continue`（v4.0.107），啃咬只打植物；所以一堆小鬼围着他又咬又喊、血量纹丝不动
- 修法：三处索敌全部 `!p.isZombie`；兜底不再回落本体；`_cycleCommandTarget` 候选过滤 `!v.isZombie`（僵尸阵营 P1/P2 都是自己人）+ 空候选时清空并飘字；HUD `cmdTxt` 去掉「你」分支
- **新增 `_hordePlantPrey(zb)`**：一个活人都没有时，就近在「有植物的房间」里挑最近 3 间随机一间、再随机一株非贴地植物当虚拟猎物（`_isPlant:true / _plant`），先啃门后啃坚果；每帧校验虚拟猎物还在 `this.plants` 里、hp>0，否则立刻作废重选
- **门板残血溅射也跳过 `isZombie`**（v4.0.91 机制）：实测把玩家瞬移到正被啃的残门旁 2.5s，血量 600→560（被自家尸潮溅射），补丁后 600→598（那 2 点是植物子弹）
