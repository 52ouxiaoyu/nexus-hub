# 2026-09-03 工作日志

## PVZ 融合植物特色升级（v3.2.34-fusionup，commit 4b62442，已推送 origin main）

**背景**：用户反馈樱桃射手（融合豌豆+樱桃炸弹）玩起来没用——射的豆子和普通豌豆一模一样。

**改动内容**：
1. **樱桃射手**（`fusion_cherrybomb_peashooter`）：
   - 普通子弹改为樱桃红/橙色视觉（新 projectile type `cherrypea`，20 伤害不变）
   - 每第 10 次攻击发射"小樱桃炸弹"（type `minicherry`，迷你樱桃贴图飞行），命中即爆，3×3 范围 900 伤害（原版樱桃炸弹 1800 的一半）
   - 死亡爆炸（1800/3×3）保留
2. **毁灭向日葵**（`fusion_doomshroom_sunflower`）：毁灭菇原贡献只有"死亡爆炸"，现增加"毁灭新星"——每 12s 对自身 5×5 内僵尸造成 400 暗影伤害 + 紫色 Boom 视觉
3. **修复隐藏 bug（重要）**：这两株融合植物的死亡爆炸**从未生效过**：
   - `for (let zombie of this.game.zombies)` —— `game.zombies` 在整个项目不存在 → 植物死亡时抛 TypeError 中断游戏帧循环
   - 范围判定用 `zombie.col` —— Zombie 类根本没有 col 属性 → NaN
   - 修复：遍历 `game.entities` 过滤 Zombie + 改用 x 距离判定（80px/格：3×3 用 <150，5×5 用 <200，与 explodeNow 一致）
4. 审查全部 11 种融合植物：其余 9 种（豌豆向日葵/坚果射手/寒冰坚果/孢子地雷/地刺坚果/钢地刺高坚果/猫尾草类等）都已叠加双亲主动特性，无同质化问题，不改。

**验证**：新增 `_verify_upgrades.js`（22/22：第10发为minicherry、前9发cherrypea、爆炸900×3×3 溅射、新星400×5×5 范围外不掉血、两株死亡爆炸修复、向日葵产阳光回归）+ `_verify_bomb_auto` 12/12 + `_verify_samecell` 8/8 全部通过。

**技术备忘**：页面 class（Plant/Zombie/Projectile）是全局词法绑定——`page.evaluate` 里可直接用裸类名，但**不挂在 window 上**（`window.Plant === undefined`），曾导致测试脚本踩坑。

## PVZ 植物头僵尸（v3.2.35-planthead，commit d79494a，已推送 origin main）

**背景**：用户要求"加一些有植物头的僵尸（像豌豆射手头、坚果头之类）"，关键约束：① 头上的植物是**基础植物而非融合植物**；② 这种僵尸**只在融合进化模式**中产生。

**4 种植物头僵尸（融合模式专属，经典模式完全不刷）**：
| 类型 | 头顶植物 | HP | 速 | 特性 |
|---|---|---|---|---|
| peahead | 豌豆射手 | 560 | 20 | 中甲 |
| nuthead | 坚果 | 1300 | 15 | 重甲慢速 |
| sunhead | 向日葵 | 320 | 20 | 死后掉 25 阳光 |
| snowpeahead | 寒冰射手 | 420 | 26 | **完全免疫减速**（含全屏冰冻事件） |

**实现要点**：
- 头部 = 基础植物 GIF（71×71）作为额外 DOM img 叠在僵尸身体之上，独立 absolute + 跟随 body 每帧同步 left/top/zIndex
- 头部 = "装甲"：hp 降到 headBreakHp 触发 0.5s 掉落+旋转+淡出动画，特性（如寒冰免疫）一并失效 → 变普通僵尸
- sunhead 死亡时 push 一个 Sun 到 entities
- WaveManager 加 plantheadChance（仅 fusionMode 启用，t>75 解锁），按 peahead(35%)/nuthead(25%)/sunhead(22%)/snowpeahead(18%) 加权
- 全局重构冰冻入口：所有 `z.isSlowed = true; slowTimer = N`（Plant×4 / Projectile×2 / CollisionManager×2 / EventManager×1）统一替换为 `z.setSlow(N)`；thaw() 修复了原来直接置 false 后蓝色滤镜残留的 bug

**改动文件**：Zombie.js（构造+ 5 个新方法）、WaveManager.js（spawn 概率）、CollisionManager/EventManager/Projectile/Plant（setSlow/thaw 统一调用）。assetVersion=1788443631。

**验证**：`_verify_planthead` 14/14（双模式波次分布、DOM 头部生命周期、破甲动画、位置同步、四种特性）+ 回归 `_verify_bomb_auto` 12/12 + `_verify_samecell` 8/8 + `_verify_upgrades` 22/22 = **56/56**。

**视觉验证**：`/tmp/_heads_on_lawn.png` 截图确认四类植物头戴在僵尸头顶上形态自然、风格统一。
