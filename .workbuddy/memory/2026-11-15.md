## pvz-web v4.0.160 —— 砸罐子每关地图每局重抽 + 问号罐不再白给植物

用户原话：「问号罐里面基本全是植物，而且每集的地图都是固定的…地图尽量每次都不太一样，不然每次解法都一样，太无味。植物也尽量少一点。」

### 改了什么
- `GameLoop.js` `setupVases()`：关卡模式不再用 `L.n * 7919` 固定种子，改成 `Date.now() ^ random`；
   `chosen` 不再 `sort` 按行列排死；`types` 洗牌从 `if (!L)` 改成无条件；三条内容队列（plants/qs/zombies）加洗牌。
- `VASE_LEVELS` 全表重写：问号罐内容 57% 植物 → 51%；僵尸 12% → 27%；绿罐 44 个（L1~L6 各 3~4，L9/L10 各 6 且全出植物）。
- 新增「行内僵尸血量均衡」块（在 `poolAt` 之前）：算每行僵尸总血，超 avg×1.55 就把一只换到最闲的行。
- 金罐兜底：中间排（col 3~5）一个罐都没有时退到全部罐子。
- 开场横幅「N 只僵尸」→「紫罐 N 个」（问号罐也藏僵尸，报总数剧透、报 L.z 低报）。
- 帮助/关卡面板文案：新增「每局罐位/罐型/顺序重新抽签」「约一半植物 / 四分之一僵尸 / 两成阳光」。

### 关键工程结论（写进 MEMORY.md）
1. **随机化三星标准的前提**：v4.0.150 已把星级改成「损失植物数」，所以布局随机不破坏评价；
   如果哪天星级回到「最少行动点/步数」，随机布局会立刻让标准失效。
2. **随机布局的方差来源不是罐位，而是「行内僵尸血量分布」**。不做均衡时，两只铁桶挤同一行
   = 4 株输出也守不住，机器人每关都有一局输。均衡（换罐位不换内容）后胜率从 75% → 83~100%。
3. **降植物项又不降火力的手法**：把 `p:repeater` 换成 `p:gatlingpea`（1 株机枪 = 2 株双发），
   腾出的名额换成 `'s'`。问号罐植物占比 57% → 51% 靠这一招，火力不变。
4. **可解性底线**：场上植物 : 僵尸数 < 1.2 时机器人稳定崩（L5 8.5:8、L9 12:11、L10 12:12 都试过），
   1.4 以上才稳。末两关的解法是「绿罐给到 6 个全出植物」——植物来源从问号罐挪到绿罐，
   总数不变但玩家观感是「问号罐不再全是植物」。
5. **铁桶 1300 血是硬门槛**：每行只有 1~2 株输出时，铁桶必过。末两关必须给寒冰（减速=等效 dps ×2）
   或机枪/西瓜，光给豌豆没用。
6. `_diag_play.js` 机器人这次修了两个老毛病：① 只数僵尸「只数」不算「硬度」→ 改按 `ZHP` 权重；
   ② `plantAt(row, atkTypes.shift(), …)` 先吃卡再试种。旧版 `_verify_v4150/v4158` 内嵌机器人同病，一并修了。

### 旧验收脚本的断言要跟着规格改（不是代码坏了）
`_verify_v4158` / `_verify_v4150` 里 12 条断言写的是 v4.0.158 的规格（绿罐 4~5、L1 配额 4/8/3、

## v4.0.162 画风统一到「原版手绘写实」（用户：元素不该是 Q 版）

### 用户原话
「这是一个植物大战僵尸元素的游戏，所以它的所有元素应该不是 Q 版的，而是带了一丝现实画风。
就像正常的《植物大战僵尸》一样，比如猫尾草、泡泡龙等等，都需要这么一点现代的画风。」

### 定位到的根因（重要）
**不是素材问题** —— 植物/僵尸/种子栏/阳光池一直用原版手绘 sprites。
是我们**程序画的那部分**在拖后腿：泡泡是带硬白点的玻璃弹珠、背景是纯色渐变、
面板是圆角半透明黑块 —— 那是手机休闲手游的语法，和原版手绘贴图放一起立刻分家。

### 原版 PVZ 的三条「手绘」判据（以后加新界面直接照这三条查）
1. **每个形体都有深色轮廓**（混 0x14100a 一类的暗色，α 0.45~0.6）—— 这条是「手绘」和「扁平矢量」的分界
2. **体积靠大块低频明暗**，不靠高光点。高光点=玻璃/塑料；原版高光是「一小团柔光 + 一道短弧」
3. **颜色不是网页色值**。纯 saturated 的 #5fbf35 一看就是算出来的；往橄榄绿/灰蓝偏（#7cb43f 这类）

再加两件黏合剂：**细颗粒**（overlay α≈0.055）+ **径向暗角**（边 α≈0.16）。

### 实现要点
- `MiniGames.js` 新增工具：`lcg(seed)` / `bake(key,w,h,fn)` / `texBrush()` / `texGrain()` / `paintedPass()`
  · 纹理**一次性烘焙**成离屏 canvas，之后每帧只 drawImage —— 不能每帧用 Math.random 画草，会闪
  · `paintedPass` 在 `tick()` 里 `active.draw()` 之后调用，10 个玩法统一吃到颗粒+暗角
- `paintBub` 重写：两段线性明暗 + 深色轮廓 + 背光暗弧 + 短弧高光（删掉 v4.0.155 的硬白点）
- `panel()` 一改，10 个玩法的侧栏/场地框全部从「半透明黑圆角」变木牌（省事）
- DOM：`.mini-card` 4px 外木框 + inset 金线 + 羊皮纸 + `::before` SVG 噪点 + 0 5px 0 底部厚边
- 主游戏 `#btn-speed` / `#btn-pause` 从胶囊换木牌（KaiTi + 木纹 + 3px 底部厚边）
- 选卡弹窗 inline 样式：`border-radius:15px` + `monospace` → 木框羊皮纸 + 楷体

### 踩坑
- **调色不能一步降太多**：先把 #5fbf35 改成 #71a83c 再叠颗粒/暗角，整片砸下来是灰绿糊；
  正确顺序是「先定明暗结构、再降饱和、最后才叠颗粒」，且 `texGrain` 控制在 0.07~0.09
- `panel()` 若用 `globalAlpha=1` 会把场景背景**整块盖死**（玉米方块从绿底变棕底、发闷）→
  保留 `min(0.92, 0.42 + a*0.55)` 的透明度
- 塔/牧场这种「烘焙背景又被场地半透明压暗层盖住」的组合，压暗层 α 必须 ≤0.32，否则纹理等于白做
- **验收脚本会覆盖已跟踪的 `_vXXXX.png`**：跑完 11 套回归后有 33 张老截图变 M，
  提交前必须 `git diff --name-only -- pvz-web | grep '\\.png$' | xargs -r git checkout --`
  （用 `git status` 抓会把未跟踪的临时图也塞进去 → pathspec 报错，整条命令直接什么都不做）
- `_verify_v4138.js` 的 E 段（猫尾草泡泡龙）自 v4.0.157 起已失效（`openGame('bubble')` 早下架），
  报 `a.colsIn is not a function` 是旧账，不是新回归

## v4.0.163 泡泡牧场按色权重抽签（豌豆 30%）
用户：豌豆在牧场有两个盆，爆率偏低 → 调到 30%；寒冰/喷菇/玉米各约 20%。

- **根因不是随机不公平，是「同色要喂两盆」**：四色均分各 25% 时，豌豆色要 36 颗才够
  一份收成（6 级×3 颗×2 盆），另三色各 18 颗 —— 豌豆色天然落后一个身位，
  玩家必然卡在第二个豌豆盆。数值上要真正打平，豌豆得给到 40%（36/(36+18×3)）。
- 实现：`BubLane` 新增 `colW` + `randCol()`，**五处抽色一个都不能漏**——
  `reset()` 开局盘面、`cur/next` 初值、`advance()` 换球、`pushCeil()` 压行、
  `pushCeil` 里的 `colorFn` 兜底。漏一处就会出现「开局正常、打两分钟变回 25%」。
- `FARM_COL_W = [0.30, 0.70/3, 0.70/3, 0.70/3]`：用户给的 30+20×3=90 必须归一化，
  这里按「豌豆严格 30%、其余平分」处理；要严格 30/20/20/20 得加一个不收任何盆的
  野色（会明显加难），未采用。
- **不许靠加第 5 色解决**：nColors 从 4 加到 5 会稀释同色概率，三消直接玩不动。
- 机械龙 / 对轰 / 塔不给 `colW` → `randCol()` 走旧的 `(Math.random()*nColors)|0`，零变化。

### 验收脚本三个坑
1. 采样阈值别写死「n>3000 颗」—— 牧场 8 行 19 列一局才 49 颗，40 局 1960 颗。
2. `pushCeil` 抽样 570 颗时 se≈1.9%，p=0.3 的 30% 断言会偶发假红（实测 35.6%）→ 样本拉到 1700+。
3. 第二个豌豆盆是 `pots[4]`，不是 `pots[1]`（FARM_CROPS 顺序是 豌豆/寒冰/喷菇/玉米/豌豆）；
   测喂盆链前先把 `lane.pushCeil` 打桩，否则 6 次升级把盘面顶穿直接判负。

`_verify_v4163.js` 22/22；回归 v4162(23) v4159(26) v4157(49) 全绿。截图 `_v4163_farm.png`。
