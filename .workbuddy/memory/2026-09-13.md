## racing-3d v1.2.5 · 修复碰终点看台"被吸住开不出来"

用户反馈：车在 finish 线旁两个建筑物台子碰一下后被吸住，再也开不出来。

根因（两个叠加，都坐实）：
1. **楔形缝互推**：立柱圆碰撞体（lateral 9.5，minD 1.7 → 覆盖 7.8~11.2）与
   看台矩形有效区（中心 lateral 13、hx 1.5 + 1.0 车身余量 → 10.5~15.5）
   在横向 10.5~11.2 重叠；车进缝里圆往回推、矩形往外推，每帧打架
2. **每帧接触都扣速**：旧逻辑只要碰撞就 ×(1-0.12-0.5·headOn)（最低 ×0.38），
   持续接触下速度指数衰减到 0，油门（每帧约 +0.23 m/s）加不过衰减 → 焊死

修复（game.js collideCar 重构）：
- `_impactSlow(car, nx, nz)`：一次性冲量式扣速——closing（撞入法向速度分量）> 1.2 m/s
  且 `car._hitPenCd`（0.4s）冷却结束才扣一次，系数 0.12+0.5·min(1, closing/25)；
  刮蹭/静止接触 closing≈0 → 不扣
- 圆形推离若落点会进看台矩形有效区（`_insideRects`）则跳过，交矩形统一推出
- collideCar 签名加 `dt = 0.016`（默认值保兼容）；Player.update 传真实 dt
- 撞击音效改判 `car._impactFlag`（真实撞击才置位），刮蹭不再哒哒响

测试 T25 4 项：正面撞看台 25→9.5、刮蹭 90 帧速度不衰减（旧版≈0）、
楔形缝 240 帧速度不塌且开出 30.7m、撞树回归 25→9.5。全套 85/85。
注意：测试摆放方向错了两次——closing 的符号取决于车朝向（背对障碍开走 closing<0 不扣速，
这是新物理的正确行为）；断言前先想清楚"撞入"方向。

## tank-battle v1.4.10 — 重开后被二次拉回结算屏（9eb72fc）
- 用户反馈：游戏结束马上按空格重开，两三秒后玩着玩着又自动重开一次
- 根因：showMVPScreen() 的 5 秒 setTimeout 强制跳 showGameOverScreen() 无取消机制；
  结算 5 秒窗口内按空格重开 → 新局中途定时器到期把 state 强改 GAME_OVER 弹结算屏，
  空格又是开火键 → 下一次开炮 keydown 命中 GAME_OVER 分支再次 startGame。
  按得早窗口长、过几秒按定时器已执行完 → 与"刚结束按才明显"完全吻合
- 修复三重保险：_mvpScreenTimer 记录 id + startGame() clearTimeout；
  showGameOverScreen() 加 state==='MVP_SHOWCASE' 守卫（过期跳转忽略）；
  GAME_OVER/MVP 分支忽略 e.repeat（长按空格不再连开）
- 教训沉淀：**restart 入口必须清理所有延迟跳转类 setTimeout；强制跳转函数要校验来源状态**
- Edit 工具本次 4 连发中 2 处假成功（第 4 次复现），Python assert 替换兜底，已按惯例 grep 复核
- 验证：专项 /tmp/tank_v1410_verify.js 9/9；v1.4.9 回归 12/12（唯一差异=徽标版本断言，预期）

## racing-3d v1.2.6 · 刹车反馈强化 + 修复倒车永不生效

用户反馈：S/下 应该是刹车吧？但效果不明显。

实测结论：刹车物理本身很强（BRAKE=30 m/s²，144 km/h → 停住约 1s），
"不明显"是**零视觉反馈**——刹车和松油门滑行看起来一样。

顺带挖出一个隐藏 bug（T26.5 暴露）：**倒车从未生效**——
低速分支 `a += 8 * brake * (1 - clamp(...))` 符号写反（+8 是向前），
停稳按 S 只在 0.1~0.5 m/s 抖动，REV_MAX=-9 形同虚设（v1.2.0 起就坏）。
修复：`a -= 8 * brake * ...`。

新增刹车反馈三件套：
- 刹车灯：尾灯 emissiveIntensity 0.8 → 2.4（buildCarMesh 返回 tailM，
  注意变量名叫 tlM，return 时 `tailM: tlM`——第一次写成裸 tailM 导致
  ReferenceError 页面白屏卡 LOADING，靠 pageerror 才定位）
- 刹车点头：dive 0~0.055 rad 平滑（>4 m/s 且刹车时），rotation.x 叠加
- 高速刹车（>12 m/s）留胎痕：p.braking 标志 + frame 里 tryDrop 条件放宽
- 菜单键位注明 S/↓ 刹车、停稳倒车

测试 T26 6 项，全套 91/91；截图 /tmp/v126_brake.png 验证刹车灯出像素。
调试注意：页面卡 LOADING 先抓 pageerror（本次是 ReferenceError 白屏，
不是 cwd 问题）；`grep 多模式` 在 Bash 里返回空，必须用 Grep 工具。
本会话 Bash 的 `cd ... &&` 前缀多次被吞 → 用绝对路径 `node /path/_test.js`
（_test.js 内部用 __dirname，任意 cwd 可跑）。
